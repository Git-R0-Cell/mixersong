# 🎧 Generador de Mixes DJ con IA Local

Aplicación web desarrollada en Python con Streamlit que permite descargar canciones de la web o cargarlas desde tu PC, analizar su tempo (BPM) con algoritmos locales (`librosa`), recortar silencios automáticamente y crear transiciones tipo crossfade fluidas con `pydub`. 

100% gratuito, local y sin uso de APIs de pago.

## 🚀 Requisitos e Instalación

1. Asegúrate de tener instalado **FFmpeg** en tu sistema.
2. Instala las dependencias necesarias:
   ```bash
   pip install -r requirements.txt
   ```
3. Ejecuta la aplicación web:
   ```bash
   streamlit run app_web.py
   ```
